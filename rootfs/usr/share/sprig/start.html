Sprig Linux

This is lynx's start page on Sprig Linux, a file on this computer (/usr/share/sprig/start.html; another start page: STARTFILE in /etc/lynx.cfg, or lynx followed by an address).

Sites that work well in lynx

  • NPR: news, text only
  • CNN Lite: news, text only
  • DuckDuckGo Lite: search
  • Wikipedia (big pages take a while)
  • Hacker News
  • Lynx's home page and its help

Keys

  • Up and Down: from link to link; Right or Enter: follow it; Left: back
  • g: go to an address; d: download the link; /: search the page
  • Space and b: a page down and up; h: help (online); q: quit

On an emulated PC the first secure (https) page from a site takes several seconds; the next ones from it are quicker, also after lynx starts again.
